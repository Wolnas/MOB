# Bolivia Oncology Transparency Dataset

## Description

Open dataset created during Cursor Buildathon Bolivia 2026.

The objective is to improve transparency in oncology referral pathways in Bolivia.

The dataset supports:

- Symptom triage
- Hospital recommendation
- Capacity visualization
- Medical decision support

---

## Included datasets

- hospital_capacity.csv
- hospitals_coordinates.csv
- hospital_statistics.csv
- triage_red_flags.csv
- symptom_questions.csv
- follow_up_templates.csv
- doctor_demo_cases.csv

---

## Sources

- Ministry of Health Bolivia
- SEDES
- Public Hospital websites
- NICE Guidelines
- NHS Guidelines
- Kaggle Brain Tumor MRI Dataset

---

## Limitations

This dataset DOES NOT diagnose diseases.

The triage rules are based on public clinical guidelines.

Hospital capacity may change over time.
